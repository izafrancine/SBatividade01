# Item 3

1. Abra o primeiro terminal e inicie o servidor

`python ServidorChat.py`


2. Abra o segundo terminal e entre como primeiro usuário

`python ClienteChat.py`


3. Abra o terceiro terminal e entre como segundo usuário

Repita os mesmos comandos do passo 2, mas com outro nome. 

4. Converse

Digite uma mensagem em qualquer terminal de cliente e aperte Enter. Ela aparece no outro terminal.

5. Encerre

Nos clientes, digite sair e aperte Enter.
No servidor, aperte Ctrl+C.
